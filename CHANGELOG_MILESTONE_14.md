# Milestone 14 Changelog

## 1.0.0 — Forecast Core

- add forecast-domain value kinds,
- add immutable ForecastPoint and ForecastSeries,
- add deterministic interpolation,
- add ForecastSnapshot and ForecastReport,
- add ForecastProvider protocol,
- add provider-neutral ForecastEngine,
- add offline StaticForecastProvider,
- add seven automated tests,
- add example and RFC-0009.
