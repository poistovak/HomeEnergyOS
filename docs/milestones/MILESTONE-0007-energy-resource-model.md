# Milestone 7 — Energy Resource Model

## Goal

Model the home as an energy system rather than as a list of devices.

```text
Solar Roof
    ↓
House AC Bus
   ├── Omoda 9
   ├── Daikin Altherma
   ├── House Loads
   └── Distribution Grid
```

Completion requires stable identities, directed flows, explicit losses, discovery, topology queries, tests and Ruff.
