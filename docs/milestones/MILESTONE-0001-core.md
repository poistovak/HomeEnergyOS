# Milestone 1 — HEOS Core

**Target:** 0.1.0

## Goal
Create a small, deterministic, vendor-independent runtime kernel.

## Included
- runtime configuration,
- event bus,
- device registry,
- scheduler,
- kernel tick lifecycle,
- automated tests.

## Completion criteria
1. One kernel tick builds state and produces a decision.
2. Lifecycle events are observable.
3. Devices are discoverable by capability.
4. Scheduled tasks run deterministically.
5. All Core tests pass.
