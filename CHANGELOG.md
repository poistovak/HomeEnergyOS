# Changelog

## 0.3.0 — Digital Twin

- add immutable `DigitalTwin`,
- add normalized power, EV, charger, climate, price and forecast states,
- add device-health aggregation,
- add source quality and freshness,
- add conservative Autopilot readiness gate,
- preserve backward compatibility through `HouseState.to_digital_twin()`,
- add RFC-0004 and automated tests.

## 0.2.0 — Neuron

- add public Brain API,
- add Candidate model,
- add deterministic Decision Engine,
- add Brain Orchestrator,
- add built-in EV Charging Brain,
- add RFC-0002 and RFC-0003.
